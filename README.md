# PrepTrack — Interview Practice Tracker

A responsive dashboard that helps students organize and track their weekly interview preparation.

## Features

- Weekly interview preparation dashboard
- Total, completed, and pending task statistics
- Weekly completion progress bar
- Add, edit, delete, and complete tasks
- Filter tasks by day and category
- Dark mode and light mode
- Responsive design for mobile and desktop
- Saves tasks and theme preference using localStorage
- Sample tasks available for first-time users

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or package installation is required.

## Assumptions

- This is a frontend-only application.
- Tasks are stored in the current browser using localStorage.
- Data is not synced between different devices or browsers.
- Sample tasks are provided when no saved tasks exist.
- The progress percentage is based on completed tasks divided by total tasks.

## Future Improvements

- Weekly calendar view
- Search tasks
- Set custom weekly goals
- Export preparation progress

Built as a frontend machine coding practice project.
